# 📚 TOKO BUKU ONLINE

**Tugas Ujian Tengah Semester (UTS) – Pemrograman Web 1**

Selamat datang di project **Toko Buku Online**! Website ini merupakan aplikasi pemesanan buku berbasis web yang dibuat menggunakan HTML, CSS, dan JavaScript.

Website ini dirancang untuk membantu pengguna melihat katalog buku, mengelola stok, melakukan pemesanan, dan memantau status pengiriman.

---

## 🌿 Tampilan Website

Website menggunakan desain modern dengan nuansa warna hijau yang memberikan kesan nyaman, sederhana, dan mudah digunakan.

## ✨ Fitur Website

- **Login:** Halaman masuk menggunakan email dan password.
- **Lupa Password:** Formulir bantuan untuk pengguna yang lupa password.
- **Daftar Akun:** Tampilan formulir pendaftaran akun.
- **Dashboard:** Menampilkan halaman utama dan ringkasan informasi.
- **Informasi Stok/Katalog:** Menampilkan daftar buku dan informasi stok.
- **Tambah Stok Buku:** Menambahkan data buku melalui JavaScript.
- **Checkout:** Menampilkan dan mengelola pesanan buku.
- **Tracking Pengiriman:** Melihat informasi dan status pengiriman pesanan.
- **History Transaksi:** Menampilkan riwayat transaksi.
- **Local Storage:** Menyimpan data sementara pada browser.

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |

## 🚀 Cara Menjalankan Website

1. Download atau clone repository ini.
2. Buka folder project menggunakan Visual Studio Code.
3. Pastikan seluruh file dan folder berada pada struktur yang benar.
4. Buka file `index.html`.
5. Klik kanan pada file tersebut.
6. Pilih **Open with Live Server**.
7. Website akan terbuka melalui browser.
